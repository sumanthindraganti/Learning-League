# 🌟 C Programming E-Learning Platform

> An interactive web-based platform to learn C programming through videos, quizzes, and engaging mini-games.

🌐 **Live Site**: [https://quiet-praline-d07599.netlify.app/dashboard](https://quiet-praline-d07599.netlify.app/dashboard)

---

## 📚 About the Project

This is a gamified **E-Learning platform** designed to teach the fundamentals of C programming. It features a progressive level-based structure, each level covering key concepts of the C language through:

- 🎓 Instructional videos  
- ❓ Quizzes and code puzzles  
- 🎮 Mini-games for hands-on learning  
- 📈 Dashboard to track progress  
- 🏅 Certificate of completion

The platform is ideal for beginners and students who want to master C programming in an interactive way.
